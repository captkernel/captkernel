# captKernel

Claude Code plugins and skills that make Claude work like it knows what it's doing.

Add the hub marketplace once:

```
/plugin marketplace add captkernel/plugins
```

| Plugin | What it does | Repo | Install |
|---|---|---|---|
| skills-curator | Evaluate, recommend and customize Claude skills before you install them; remembers every decision. | [Skills_Curator](https://github.com/captkernel/Skills_Curator) | `/plugin install skills-curator@captkernel` |
| claunchpad | One skill that sets a project up for Claude: CLAUDE.md, persistent memory, agent teams, councils. | [Claunchpad](https://github.com/captkernel/Claunchpad) | `/plugin install claunchpad@captkernel` |
| thinking-tools | Council, premortem, red team, pressure test, brutal assessment. | [claude-thinking-tools](https://github.com/captkernel/claude-thinking-tools) | `/plugin install thinking-tools@captkernel` |
| writing-tools | Humanize, tighten and hook-writing skills. | [claude-writing-tools](https://github.com/captkernel/claude-writing-tools) | `/plugin install writing-tools@captkernel` |
| everyday-tools | Cheap flights, fare myths, focus steps, fast learning plans. | [claude-everyday-tools](https://github.com/captkernel/claude-everyday-tools) | `/plugin install everyday-tools@captkernel` |

More at [captkernel.com](https://captkernel.com).
